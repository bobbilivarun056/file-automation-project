# File Organizer Automation

## Description

This project is a Python automation tool that organizes files
into different folders based on their file extensions.

## Features

- Automatically organizes files
- Uses OS module
- Uses exception handling
- Generates operation logs
- Supports user input
- Creates folders automatically
- Sorts files by file type

## Technologies Used

- Python
- OS module
- Shutil module
- Logging module
- VS Code

## File Categories

- Images
- Documents
- Audio
- Videos
- Archives
- Others

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python file_organizer.py
